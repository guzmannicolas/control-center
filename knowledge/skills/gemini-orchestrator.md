# Skill: Gemini Multi-Model AI Orchestrator

The AI layer in Control Center leverages the Google Gen AI SDK (`@google/genai`) to power agents, data enrichment, system administration, and conversational tools.

## 1. Model Pool & Failover Strategy

To bypass transient rate limits (429 Quota Exceeded), regional downtime, or 404 deprecations, requests iterate across an ordered pool:

```typescript
const MODEL_POOL = [
  'gemini-3.5-flash-lite',
  'gemini-3.6-flash',
  'gemini-3.5-flash',
  'gemini-3.1-flash-lite',
  'gemini-flash-lite-latest',
];
```

If an invocation encounters an error, the orchestrator immediately retries with the next model in the sequence before failing the request.

## 2. Configuration Standards

- **Temperature**: Always set to `0.0` for structured data generation, system administration tasks, and SQL generation to eliminate hallucinations.
- **Structured JSON Output**:
  - `responseMimeType: 'application/json'` enforced on all classification and enrichment calls.
  - Zod schemas validate JSON payloads before persisting to PostgreSQL.

## 3. Persistent Agent Sessions

Agent chat interactions are saved in PostgreSQL via the `ChatSession` model:
- `id`: Session UUID.
- `title`: Autogenerated session summary.
- `messages`: JSON array of user and model turns.
- `context`: Active working parameters, selected model tier, and system directives.

## 4. Web Speech Voice Dictation

Voice input in Control Center (`apps/web/src/pages/Agents.tsx`) utilizes the HTML5 Web Speech API (`webkitSpeechRecognition`) with an intelligent buffer:
- **Deduplication Engine**: Filters consecutive duplicate words caused by interim and final transcript overlap.
- **Language**: Defaults to `es-AR` (Argentine Spanish) for natural operator dictation.
- **Real-Time Token Insertion**: Appends voice transcript directly into the chat prompt area without clearing active drafts.
